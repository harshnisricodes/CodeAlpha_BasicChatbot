Project Name: Basic Chatbot

Description:
This is a simple Python chatbot that responds to basic user inputs such as greetings, asking its name, and asking how it is doing. The chatbot runs in a loop until the user types "bye", after which it exits gracefully.

Technologies Used:
- Python

Features:
- Responds to greetings
- Answers basic questions
- Exits on user command
- Easy to understand and modify them
